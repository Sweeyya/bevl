title: Corners are sharp by default
tags: corners, radius, brand, style, taste
seen: 1
---
Mistake: Generated UI and fix messages reached for rounded corners, which the owner does not want and which read as a generic AI look.

Rule: Brand radius defaults to 0 everywhere, including 3D frames and nav links. Only use a radius when the brand file explicitly sets one. Rule brand/sharp-corners warns otherwise.
