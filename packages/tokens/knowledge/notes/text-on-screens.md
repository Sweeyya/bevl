id: text-on-screens
kind: note
title: Text on screens is an HTML overlay, not a 3D object
tags: html, text, sections, contrast, layout
---
Section html is an overlay on the page. It fills the viewport, shows one section at a time, is centred vertically and sits at the left with padding. It does not follow a 3D screen.

Keep the text real HTML with a heading per section. Over bright or busy 3D, wrap it in a backing panel with a solid brand colour and a max width so it still fits on phones.
