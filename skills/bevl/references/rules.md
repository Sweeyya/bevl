# Checker rules

Every rule has a stable id (`group/name`), a severity, and a `Fix:` message. Severity here is the default. Some rules report a lower severity in special cases (for example `budgets/triangles` warns near the budget, `load/webgl` reports info on software renderers). Budgets come from `bevl.budgets.json` and can be overridden per project in `bevl.json`.

Hard gates (a failing error sets the score to 0): `load/ready`, `render/not-blank`, `scroll/reaches-every-section`.

Passing means score >= 90 and zero errors.

| Rule                           | Severity | Meaning                                                                                                                                                                                  | Typical fix                                                                                                                                                |
| ------------------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `load/ready`                   | error    | `window.__bevl.ready` must resolve within the ready budget (3000 ms desktop, 5000 ms phone). Hard gate.                                                                                  | Make sure `BevlSite` mounts the bridge and assets load. Check console and asset paths. Off localhost set `testMode` to `always` in `bevl.json`.            |
| `load/console-errors`          | error    | No `console.error` calls or uncaught exceptions during load.                                                                                                                             | Fix the JavaScript error shown. An `invalid choreography` message means fix that field.                                                                    |
| `load/webgl`                   | error    | WebGL2 must be available. Info only when a software renderer is used.                                                                                                                    | Use a browser with WebGL2 and add a static HTML fallback.                                                                                                  |
| `render/not-blank`             | error    | The screenshot must not be one flat color (blank, black, white, magenta). Hard gate.                                                                                                     | Add geometry, at least one light, and put the camera inside the scene.                                                                                     |
| `render/no-nan`                | error    | No scene object may have NaN in position, rotation or scale.                                                                                                                             | Fix camera or layout math that divides by zero or uses an empty path. Have at least one section.                                                           |
| `budgets/triangles`            | error    | Triangle count under budget (500000 desktop, 150000 phone). Warns when near the budget.                                                                                                  | Lower-poly models, merge meshes, instancing. Run `optimize_assets`.                                                                                        |
| `budgets/draw-calls`           | error    | Draw calls under budget (200 desktop, 80 phone).                                                                                                                                         | Merge geometries, use instanced meshes, share materials.                                                                                                   |
| `scroll/reaches-every-section` | error    | Every section is reachable by scrolling top to bottom. Hard gate.                                                                                                                        | Give every section a `<Section id>` and a beat. The DOM anchor `id="section-<id>"` must exist.                                                             |
| `scroll/no-jumps`              | error    | The camera never teleports: max move per scroll step is 1.5 m.                                                                                                                           | Add keyframes, use `path: "curve"`, or reduce distance between beats. `allow.fastMoves` only if the user asked.                                            |
| `scroll/no-roll`               | error    | Camera up stays within the roll limit of world up.                                                                                                                                       | Avoid sideways tilts and `lookAt` positions that force roll. `allow.roll` only if the user asked.                                                          |
| `scroll/snap-settles`          | warn     | After the user stops, progress must come to rest on a beat.                                                                                                                              | Remove `snap: { mode: "none" }` or accept the warning if snapping is intentionally off.                                                                    |
| `scroll/snap-no-trap`          | error    | Every beat can be left in both directions by keyboard and by wheel.                                                                                                                      | Lower `snap.commit`, raise `input.wheelMultiplier`, or use snap mode `directional`.                                                                        |
| `scroll/deterministic`         | error    | The same seed gives the same camera at the same scroll positions.                                                                                                                        | Use the seeded `rand()` in behaviors, not `Math.random`, `Date.now` or `performance.now`.                                                                  |
| `scroll/motion-allowances`     | info     | Lists each `allow` opt-out in use. The matching check is skipped.                                                                                                                        | Remove the `allow` flag unless the user asked for that motion.                                                                                             |
| `html/section-text`            | error    | Every section has a heading and real, non-empty text in the HTML layer.                                                                                                                  | Pass the section's text with the Section `html` prop.                                                                                                      |
| `html/headings`                | warn     | Exactly one `h1`, and heading levels do not skip.                                                                                                                                        | Use one `h1` (the hero) and `h2` for the other sections.                                                                                                   |
| `seo/title`                    | error    | The page has a non-empty `<title>`.                                                                                                                                                      | Add `<title>` to the `<head>` of `index.html`.                                                                                                             |
| `seo/meta-description`         | warn     | The page has a meta description.                                                                                                                                                         | Add `<meta name="description" content="...">` to `index.html`.                                                                                             |
| `a11y/keyboard`                | error    | Tab reaches the nav and every nav link.                                                                                                                                                  | Add `<BevlA11y config={...} />` from `@bevl/a11y`; do not hide nav links with `display:none` or `visibility:hidden`.                                       |
| `a11y/keyboard-reaches-beats`  | error    | Arrow keys, Home and End reach every beat in order.                                                                                                                                      | Do not stop keydown for ArrowDown, ArrowUp, Home, End, PageDown, PageUp or Space on `window`. Keep beats at least 0.001 apart.                             |
| `a11y/reduced-motion`          | error    | With `prefers-reduced-motion` on, the camera travels under 10% as far, the active section still changes, and the keyboard reaches every beat. Skipped when `allow.reducedMotion` is set. | Remove `reducedMotion.mode: "none"` (the default already holds the camera still and fades sections), or add `reducedMotion.tracks` with tiny camera moves. |
| `scroll/no-spin`               | error    | The camera turns less than 15 degrees per scroll step. Skipped when `allow.spin` is set.                                                                                                 | Spread the turn over more of the scroll range, or add more keyframes. Only set `allow.spin` if the user asked for it.                                      |
| `scroll/no-free-roam`          | error    | W, A, S, D and mouse drag do not move the camera off the choreography.                                                                                                                   | Remove key and drag handlers that move the camera.                                                                                                         |
| `nav/menu-exists`              | error    | A real `<nav>` has one visible link per section.                                                                                                                                         | Add `<BevlA11y config={...} />` through the `overlay` prop.                                                                                                |
| `nav/link-glides`              | error    | Clicking a nav link glides to the beat with no camera jump.                                                                                                                              | Navigate with the `goToBeat` context function, not by setting the camera.                                                                                  |
| `nav/buttons-work`             | error    | Every nav button and link does something when clicked.                                                                                                                                   | Wire every nav control to a beat or a real action.                                                                                                         |
| `html/no-canvas-copy`          | error    | No 3D text mesh holds more than 40 characters.                                                                                                                                           | Put body copy in the Section `html` prop.                                                                                                                  |
| `render/fallback`              | error    | Without WebGL, a static fallback shows every section title.                                                                                                                              | Keep the built-in fallback, or pass the `fallback` prop to `BevlSite`.                                                                                     |
| `budgets/texture-mb`           | error    | Texture memory stays under budget (64 MB desktop, 24 MB phone).                                                                                                                          | Downscale textures or run `bevl optimize`.                                                                                                                 |
| `load/failed-requests`         | error    | No network request fails with an HTTP error.                                                                                                                                             | Fix missing asset paths such as models and textures.                                                                                                       |
| `a11y/contrast-over-3d`        | error    | Text over the 3D scene has at least 4.5:1 contrast (3:1 for large text).                                                                                                                 | Use the suggested text color, or add a dark or light backing behind the text.                                                                              |
| `brand/palette`                | warn     | Every non-neutral material color is within a perceptual distance (CIE76 ΔE 10) of a brand palette color. Skipped when no brand is passed.                                                | Use `<BrandMaterial role=...>` or colors from `src/brand.tokens.json`.                                                                                     |
| `brand/fonts`                  | warn     | Visible nav, heading and paragraph text use the brand fonts. Skipped when no brand is passed.                                                                                            | Remove custom `font-family` rules so text inherits the brand font.                                                                                         |

Rules for the `mascot` group are planned and may appear in newer versions. Run `bevl check` and trust the ids in the report over this table.
